# Shelf Signal v2

Interactive results for Group 3's forecasting project (Time Series Analysis and Forecasting, UCLA Anderson):
**Can AI foundation models beat traditional statistical models?** Daily demand for 5,748 Walmart food items
(M5 data, 4 California stores), 28-day test window May 23 – Jun 19, 2016.

**Live dashboard:** https://shihan-2002.github.io/shelf-signal-dashboard/

Tabs: Overview · Forecast explorer · Model comparison · AI lab (Chronos vs Claude) · Order planner (newsvendor) · Ask the analyst · About.
Open a tab directly with `#explorer`, `#compare`, `#ailab`, `#planner` or `#ask` at the end of the link.

Models: AutoETS, AutoARIMA, LightGBM, Chronos-Bolt, seasonal naive, an AutoETS + LightGBM ensemble, and Claude (on a 112-series subset).

This page extends our teammate's original [Shelf Signal](https://jing0712.github.io/shelf-signal/)
([code](https://github.com/Jing0712/shelf-signal)) with this project's models and results.
It is generated by `src/export_dashboard.py` in the group's project repository; the data is embedded in `index.html`.
